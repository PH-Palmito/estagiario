# Leitura Visual

## Gatilhos
- tela
- imagem
- grafico
- print
- clipboard
- o que aparece
- analisar imagem

## Objetivo
- Interpretar tela, imagem, grafico ou clipboard combinando OCR, geometria e modelo visual quando disponivel.

## Passos
- Capturar ou ler a fonte visual solicitada.
- Extrair texto legivel com OCR quando aplicavel.
- Usar modelo visual local quando a pergunta depender de semantica, grafico ou layout.
- Explicar incertezas quando a imagem estiver cortada, pequena ou pouco legivel.

## Riscos
- OCR pode confundir numeros e acentos.
- Graficos exigem cuidado com escala e eixo.

## Comandos relacionados
- analisar tela
- ler imagem
- analisar grafico
