# Navegacao Web

## Gatilhos
- navegador
- abrir site
- ler pagina
- resumir pagina
- clicar
- pesquisar na web

## Objetivo
- Navegar, ler, resumir e interagir com paginas de forma previsivel e segura.

## Passos
- Preferir leitura de pagina ou texto selecionado antes de inferir.
- Para cliques e formularios, identificar alvo com texto, posicao ou contexto visivel.
- Pedir confirmacao antes de compras, envios, logins sensiveis ou acoes irreversiveis.
- Resumir paginas em linguagem curta quando estiver em voz.

## Riscos
- Paginas mudam dinamicamente.
- Acoes em sites podem ter efeito externo.

## Comandos relacionados
- ler pagina
- resumir tela
- clicar no item
